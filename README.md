# worst-ai-line-01

A single pickup line an AI should never deliver: a flat percentage match, a face helpfully saved in three locations, and a dinner invitation framed as a retention discussion. `main.ts` imports the line from `line.ts` and writes it, with no trailing newline, to `entry.txt` inside the directory named by `MAKEFUN_OUTPUT_DIR` (default `output`).
